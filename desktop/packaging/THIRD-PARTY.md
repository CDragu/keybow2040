# Keybow Codex Windows package

The application uses the following unmodified runtime components. They are
distributed as separate files in the application directory.

- [Python 3.12](https://www.python.org/downloads/source/) under the [Python Software Foundation License](https://docs.python.org/3/license.html).
- [PySide6 Essentials and Shiboken 6.12.0](https://download.qt.io/official_releases/QtForPython/) and [Qt 6.12](https://download.qt.io/archive/qt/) under the [GNU Lesser General Public License v3](https://www.gnu.org/licenses/lgpl-3.0.html). The LGPL permits replacing the bundled Qt libraries with compatible modified copies and reverse engineering to debug those changes. The linked upstream archives provide the corresponding source.
- [PyInstaller](https://github.com/pyinstaller/pyinstaller) under [GPL with a bootloader exception](https://pyinstaller.org/en/stable/license.html).
- [Inno Setup](https://jrsoftware.org/isinfo.php) under its [license](https://jrsoftware.org/files/is/license.txt).

Codex CLI is installed separately.
